
# Movie App (React)

## Overview

This project is a movie web application built with React that consumes data from the TMDB API. Users can browse popular movies, view detailed information and save their favorite titles for quick access.

## Features

* Browse popular movies
* View movie details
* Save favorite movies
* Prevent duplicate favorites
* Redirect users to trailer search
